单页面应用说明文档
================

项目概述:
--------
这是一个基于 Django 的单页面应用(SPA)，包含三个主要功能模块：
1. Page1 - 控制台: 模拟系统控制台，支持命令交互
2. Page2 - 学生信息: 显示个人资料和技能信息
3. Page3 - 文件浏览器: 展示项目文件结构

技术特性:
--------
前端技术:
- 纯 JavaScript 单页面应用
- 无刷新页面切换
- 实时命令交互系统
- VS Code 风格界面设计

交互功能:
- 标签页切换
- 控制台命令执行
- 命令历史记录
- 实时状态更新
- 技能信息展示

文件结构:
--------
templates/hello/single_page.html  - 主页面模板
static/hello/js/singlepage.js     - 交互逻辑脚本
mystie/singlepage_info.txt        - 说明文档

使用说明:
--------
控制台命令:
help        - 显示帮助信息
clear       - 清空控制台
time        - 显示当前时间
student     - 显示学生信息
version     - 显示版本信息
switch page1 - 切换到控制台
switch page2 - 切换到学生信息
switch page3 - 切换到文件浏览器
